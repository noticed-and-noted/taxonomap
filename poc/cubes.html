Cubes and GBIF, routed per view

Reads the pre-counted cubes from pipeline/ with hyparquet and HTTP range requests, as the app would from Hugging Face, fetching only the cells in view. GBIF's own tiles draw the world view and any filter the cubes don't hold. Each run is timed and its network use counted; what's already loaded stays cached.

Months, record type and photos aren't in the map cube, so they send the map to GBIF.
